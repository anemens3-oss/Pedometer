# 📱 STEPFLOW — Шагомер (Landing Page)

Современный посадочный лендинг для презентации будущего мобильного приложения-шагомера **StepFlow** под Android (.APK / Google Play) и iOS (App Store).

> ⚠️ **Статус проекта:** Приложение в данный момент находится **в активной разработке**. Загрузка APK и ссылки на сторы будут подключены ближе к релизу.

---

## 👨‍💻 Обо мне и о проекте

Я — начинающий разработчик, активно изучаю фронтенд и верстку.

Этот проект — **мой первый практический опыт работы со скролл-анимациями** (scroll-driven animations на чистом CSS). В процессе создания я экспериментировал с эффектами появления контента при прокрутке и адаптивной версткой под разные экраны.

Любой фидбэк, советы по чистоте кода или пулреквесты горячо приветствуются!

---

## ✨ Что реализовано на странице

- **Первый опыт Scroll-driven анимаций:** плавное появление скриншотов и заголовков при прокрутке страницы с помощью современных нативных свойств `animation-timeline: view()` и `animation-range`.
- **Динамический Hero-блок:** полноэкранное фоновое автовоспроизводимое видео (`<video autoplay muted loop>`).
- **Адаптивная верстка:** страница перестраивается под смартфоны и планшеты благодаря `clamp()`, `flex-wrap` и `@media`-запросам.
- **Чистый стек:** сайт написан полностью вручную на чистом HTML5 и CSS3 без сторонних библиотек и тяжелых JS-скриптов.

---

## 🛠 Стек технологий

- **HTML5:** семантическая структура (`<section>`, `<article>`, `<video>`).
- **CSS3:** Flexbox, CSS Keyframes, CSS Scroll-driven Animations, медиа-запросы.
